# Supabase

Base Supabase integration for React + Vite + TypeScript projects.

## Installed package

- @supabase/supabase-js

## Installed files

- src/lib/supabase.ts
- .env.example

## Setup

Copy `.env.example` to `.env` and provide your Supabase project credentials.

Required variables:

VITE_SUPABASE_URL=
VITE_SUPABASE_ANON_KEY=

Do not commit `.env`.
