# Zustand

Zustand state management boilerplate for React + Vite + TypeScript.

## Installed package

- zustand

## Installed files

- src/store/exampleStore.ts

## Usage

Use Zustand for shared client-side application state.

Examples include:

- UI preferences
- filters
- temporary application state
- shared selections
- multi-component workflows

Server data should generally be handled by a server-state solution such as TanStack Query.
